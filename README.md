# SII-Editor-
 Утилита для Euro Truck Simulator 2 и American Truck Simulator, позволяющая переносить тюнинг грузовиков и прицепы между профилями.  Программа избавляет от необходимости повторно покупать технику и вручную настраивать её в другом профиле. Перенос выполняется через файлы сохранения game.sii. Для их расшифровки требуется SII_Decrypt.
